# AGENTS.md: brief for coding agents

This repo is a personal DSA learning tracker. Read this before changing anything.

## Purpose
- The owner learns DSA in Java with a Gemini mentor skill (`skill/dsa-mentor/`).
- `progress.yaml` is the single source of truth for progress. Everything else is derived or is a solution.
- Outputs generated from it: the dashboard block in `README.md`, `mistakes.md`, `docs/progress.json`.

## Hard rules
1. Never hand-edit between `<!-- DASHBOARD:START -->` and `<!-- DASHBOARD:END -->` in `README.md`, nor `mistakes.md`
   or `docs/progress.json`. Change `scripts/dsa.py` and regenerate with `python scripts/dsa.py dashboard`.
2. Keep snapshot compatibility. The mentor emits `SESSION_STATE` YAML in a ```dsa-snapshot fence. Existing keys:
   `last_updated, path, modules_completed, module_number, module_name, current_topic, topic_status,
   topics_completed_in_module, topics_pending_in_module, pattern_mastery, weak_areas_to_reinforce,
   homework_assigned, reviews_due, mistakes_log, deviations`. Unknown keys must be ignored, never crash.
3. Solutions are Java 21 only, one package per module/topic (`dsa.m02.sliding_window`), class `LcNNNN<PascalTitle>`
   with a nested `public static class Solution`. Tests are JUnit 5 in the mirrored package.
4. Do not invent problem links or LeetCode data. Titles and difficulties come from `curriculum/curriculum.json`.
5. `curriculum/curriculum.json` is generated by `scripts/build_curriculum.py` from `skill/dsa-mentor/references/`.
   Edit the markdown, then regenerate. Do not hand-edit the JSON.
6. Python scripts: standard library plus PyYAML only. Must run on Windows, macOS and Linux (use `pathlib`,
   write files as UTF-8 with `\n` newlines).

## Commands
```
python scripts/dsa.py status | due | export | dashboard
python scripts/dsa.py snapshot FILE
python scripts/dsa.py new LC [--title T --module N --topic G]
python scripts/dsa.py solved LC [--attempts N --hints N]
python scripts/build_curriculum.py
mvn -q test
```
Set `DSA_TODAY=YYYY-MM-DD` to make date-dependent output deterministic.

## Data model (progress.yaml)
`meta`, `state` (latest session), `topics` (name -> module/status/stage/completed_on), `patterns`, `weak_areas`,
`reviews` ([{topic, due, type}]), `homework`, `mistakes` ([{date, text}]), `deviations`, `problems`
("LC3" -> title/difficulty/group/module/status/attempts/hints/first_touched/first_solved/path), `history`.
